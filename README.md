# Book Scraper
This project is a web scraper designed to extract information about books from multiple web pages. The scraped data includes titles, price, star rating and other relevant details. The data is stored in a structured format for further analysis or use.

## Features
- Scrapes multiple pages of books from specified websites.
- Extracts relevant information such as title, price, star rating.
- Saves the scraped data in a structured format (e.g., CSV, JSON).
- Handles pagination to scrape data from multiple pages.

## Technologies Used
- Python
- Beautiful Soup (for HTML parsing)
- Requests (for making HTTP requests)
- Pandas (for data manipulation and storage)
